# monDico

Site vibe codé par Sophie Boyer, avec l'utilisation de Chat GPT.

## État des données

- 11478 fiches (noms communs, verbes, adverbes, adjectifs)
- La base de donnée contient essentiellement des mots adaptés aux enfants, elle ne contient pas d'insultes et exclut des définitions les sens détournés (à caractère sexuels notamment).

## Illustrations

- 1211 noms sont illustrés. Les illustrations ont été récupérées sur le site Vikidia (encyclopédie collaborative pour les enfants) et sont donc adaptées aux enfants. La source de l'image est affichée.

# Révision du vocabulaire religieux

Les définitions sont rédigées pour décrire les usages des mots et les croyances,
sans affirmer ni contester la vérité d’une religion. Les formulations « considéré
comme sacré » et « les croyants reconnaissent » attribuent explicitement les
croyances à ceux qui les partagent. Les exemples ne demandent pas à l’élève
une pratique religieuse et ne supposent pas sa croyance.

## Netlify

Le site est statique, sans serveur ni clé d’API. Commande de compilation : `npm run build`. Dossier publié : **dist**. Les fichiers dist ne sont pas inclus dans cette mise à jour : la compilation les reconstruit à partir du projet complété.
